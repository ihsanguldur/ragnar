Stratus Sync User Guide

1. About Stratus Sync

Stratus Sync keeps files in sync between a team's computers and phones. The app runs on Windows, macOS, iOS and Android, so mobile devices are supported.

Stratus Sync is sold in two plans. The Team plan costs 120 TL per user per month and includes 1 TB of shared storage. The Enterprise plan is priced by contract.

Files are stored in data centers in Dublin and Stockholm.

2. Setup and Sync

A new device is added with an invitation link sent by email. The invitation link is valid for 1 hour.

A single file cannot be larger than 20 GB. Older versions of changed files are kept for 60 days in the Team plan.

3. Error Codes

When a sync problem occurs, the app shows one of the following error codes.

CodeMeaning
SX-1042The device's storage is full; free up space to continue syncing.
SX-1047Sync is paused because the device has been offline for more than 7 days.
SX-2010The file name contains characters that are not allowed.
SX-2013The file is locked by another application and will be retried in 10 minutes.
SX-3001The team's license has expired; only an administrator can renew it.
